# Matthew Finley

Personal site for Matthew Finley (Frog). It lists his current public projects and the music project sonicrift.

The page is static HTML and CSS. It does not load fonts, scripts, or images from other sites.

## Preview

From this directory:

```sh
python3 -m http.server 8080
```

Open [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

GitHub Pages is not enabled on this repository yet. After this change is on `master`, turn on Pages (Settings → Pages → Deploy from branch → `master` → `/`). The site is then served at:

https://m-fin.github.io/whynotz0idberg.github.io/
